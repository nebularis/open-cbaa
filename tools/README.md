# Tools

Utilities that support the semantic work in `ontology/`. They are not part of any runtime.

## lattice_catalog.py

Regenerates `ontology/catalog-v001.xml`, the OASIS XML catalog Protégé and the OWL API read
from the directory of the ontology they open. It maps each Open CBAA ontology IRI to its file,
and each released LATTICE version IRI to its raw file at its release tag, read from LATTICE's
[release register](https://nebularis.github.io/lattice/architecture/ontology-releases.html).
Run it after importing a new LATTICE version. Python 3.10+, standard library only, network
access to GitHub.

```bash
python3 tools/lattice_catalog.py
```

## cbaa_extract.py

Renders CBAA module drafts and table files as annotated plain text, so they can be read,
searched and diffed without Word or Excel. Python 3.9+, standard library only.

```bash
python3 tools/cbaa_extract.py .copilot -o /tmp/cbaa-txt
```

Sources may be files or directories. Each `name.ext` becomes `name.ext.txt` in the output
directory. The exit status is non-zero if any file fails.

### Inputs

| Format | Notes |
|---|---|
| `.xml` Flat OPC (Word 2007+ saved as XML) | most module drafts |
| `.xml` WordML 2003 | detected by its `w:wordDocument` root |
| `.docx` | read from the zip package |
| `.xlsx` | sheet XML parsed directly, since `openpyxl` cannot load these workbooks |

### Output markup

The drafts encode meaning in formatting (see `.copilot/cbaa.md`), and the output keeps it.

| Markup | Source formatting | Meaning |
|---|---|---|
| `«...»` | red run | embedded variable |
| `[[...]]` | blue run | referenced object |
| `{hl:...}` | highlighted run | variation letter |
| `~ ` line prefix | mostly grey (`808080`) wording | optional or conditional clause |
| `## ` line prefix | Heading paragraph style | heading |
| `⟨EN ...⟩` | endnote | variable id, name and population method |
| `⟨FN id: ...⟩` | footnote | footnote text |
| `⟪Cid: ...⟫` on the next line | Word comment | inclusion condition, guidance or drafting note |
| `<table>` and `\| ... \|` rows | Word table | table content |
| `rN: a \| b` | spreadsheet row N | non-empty cells in column order |
| `⟪A1: ...⟫` | spreadsheet cell comment | guidance, with Excel's threaded-comment boilerplate removed |

The optional-clause test measures only the clause's own wording, not inlined note text. A
paragraph is marked when more than 60% of that wording is grey.

### Known limits

- Colour codes are those the current drafts use. A new colour in later modules would be
  rendered as plain text.
- Numbering generated by Word list definitions is not reproduced. Clause numbers typed into
  the text are.
- Images and embedded objects are skipped.
